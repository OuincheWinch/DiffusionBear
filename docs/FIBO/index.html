Technical Telemetry & Engineering

Quantization & Memory Footprint on Apple Silicon

Standard bf16 FIBO 2.0 weights require over 24 GB of storage and peak above 17.4 GB in VRAM, causing out-of-memory aborts or severe OS memory thrashing on 16 GB Apple Silicon Macs. DiffusionBear's affine 4-bit MLX quantization compresses the pipeline to 7.33 GB on disk and maintains a strict runtime resident working set under 6.8 GB.
